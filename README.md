# 🖐️ BÀN TAY ẨN MÌNH

Game 2D Horror Comedy – Mystery Shop Simulator. Chạy trực tiếp trên trình duyệt (máy tính và điện thoại), không cần cài đặt.

▶ **Chơi ngay:** https://TEN-GITHUB.github.io/ban-tay-an-minh/

## Cách chơi
Khách gõ cửa → cửa sổ mở ra → nhận đơn → pha nước → giao nước → cửa đóng sầm. Mỗi ca có 6 khách.

- Máy tính: chuột hoặc phím `Space`, `1-6`, `Esc`
- Điện thoại: chạm vào nút hoặc ô cửa sổ

## Công nghệ
HTML5 + CSS3 + JavaScript + Canvas 2D + WebAudio. Một file duy nhất: `index.html`.
